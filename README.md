# Siren Voice · TT / iOS 适配版

版本：2.3.1-tt.2（流式语音显示修复）

基于 Ellina 的 [Siren-Voice](https://github.com/Ellinav/Siren-Voice) 2.3.1 修改；上游提交为 `aef6bb5ee443488edd6c0ef1e28468c9218e1975`。这是第三方适配版，原作者为 Ellina。许可沿用 CC BY-NC 4.0，完整内容见 LICENSE.txt。本次修改由 Codex 完成。

针对“TT / iPhone 连续使用一段时间后闪退”的报告，修复代码中已确认的资源累积风险；没有在用户的 iPhone 上完成真机验证，不能承诺已经消除所有闪退原因。

## 怎么安装

你需要在 GitHub **新建一个单独的公开仓库**，例如 `Siren-Voice-TT`。不要把这些文件上传到柏宝绘方案快切的仓库里。

1. 下载本 ZIP，在 iPhone「文件」App 中点击 ZIP 解压。
2. GitHub 新仓库里选择「… → Upload files」。
3. 将以下 **5 个文件全部上传到仓库根目录**：
   - `index.js`
   - `style.css`
   - `manifest.json`
   - `LICENSE.txt`
   - `README.md`
4. 提交后，仓库首页应直接看到 `manifest.json`。不要直接上传 ZIP，也不要多套一层文件夹。
5. TT 中先停用旧版 Siren Voice，完整关闭 TT 后重新打开，再安装本适配版。
6. 在「安装扩展」里输入你自己新仓库的 Git URL，例如：

   `https://github.com/你的用户名/Siren-Voice-TT.git`

7. 安装后重新启动 TT。扩展列表应显示「Siren Voice · TT/iOS 适配」，版本为 `2.3.1-tt.2`。

仍需酒馆助手（TavernHelper），与原版一致。TT 构建本身也需要允许第三方扩展；本包不会改变 TT 的平台发行限制。

## 使用时的变化

- 自动识别 TT + iPhone / iPad（含 iPad 的桌面网站模式）。目标运行环境为 iOS / iPadOS 16.4 及以上。
- TT/iOS 的整楼语音改为**播放时按句加载**，不再一次性生成并保留整楼语音。首次点场记板会准备播放，出现绿色播放图标后再点播放；开启原有自动播放时仍会自动衔接。
- 重新生成整楼语音时，新的语音也会在随后播放到对应句子时生成。
- 逐句播放时，如果当前句子已在缓存中，就从缓存读取。每句播放后及时释放播放资源。
- TT/iOS 的后台 TTS 生成最多同时执行 1 个请求；独立音效最多同时保留 4 轨。
- 调音台、电话音、心声回响及左右声场仍保留。
- 缓存检查只读取文字索引；语音历史面板在点击重听或下载时才读取对应音频。
- 原设置字段、角色卡音色字段和本机历史数据库格式不变。不会把电脑版中的本机配置自动同步到 TT。

## 修复内容

- 完整断开播放结束、播放错误和停止时的 Web Audio 效果器连接；限制重复混响脉冲缓冲。
- 复用独立 TTS 和整楼 TTS 的播放器，释放旧音频地址与解码资源。
- 防止旧播放请求的迟到异常误停新语音，切换聊天或退出页面时取消待生成任务。
- 移除按钮持有整楼音频 Blob 的行为。
- 复用 IndexedDB 连接；不再为每条缓存检查读取全库音频，保留 v3 数据库兼容性。
- TT/iOS 旁白高亮按文字段处理，减少逐字 DOM 节点；限制动画更新频率。
- 卡片观察器只处理变化的消息，减少全页面重复扫描。
- 替换试听音频时释放旧地址；IndexTTS 试听复用音频引擎。

## 已验证的范围

在 Node.js + 模拟 DOM、IndexedDB 和音频事件环境中验证：

- 原版 v3 数据库的语音读取、收藏保留、删除、并发写入和历史上限。
- 1000 次缓存存在检查不读取音频负载；整个检查没有 `getAll()` 音频扫描。
- 连续 300 段普通语音、心声、电话音的播放结束清理；这些路径只创建一个独立 TTS 播放器/音源，全部结束后无残留音频 URL 和效果器连接。
- MiniMax 请求排队、取消当前请求和跳过取消后的待执行请求。
- TT/iOS 整楼逐句加载、无新请求的缓存重听、音效池限制、停止后的迟到下载丢弃。
- Safari 16.4 目标的发布入口编译，以及打包入口的四个设置面板、MiniMax 字段、面板开关。
- 全部源文件语法与 Git diff 格式检查。

没有进行真实 MiniMax 付费 API 请求，没有在 iPhone / TT 原生 WKWebView 内测试实际解码、系统内存回收或后台播放。上述结果是回归测试结果，不是真机无闪退保证。

## 如何试用

安装后先播放几段语音，再连续使用到原来容易闪退的时长；确认扩展列表版本正确，并且旧版已停用。

若仍有问题，记录 TT 版本、iOS 版本、使用的 TTS 渠道，以及闪退前正在执行的操作，以便继续定位原生运行时问题。

需要回退时，停用本版，恢复原版并重新启动 TT。本版没有升级历史数据库版本。

## TT 流式语音框闪烁修复（2.3.1-tt.2）

- 语音正则只接受同名结束标签（`</speak>`、`</inner>`、`</phone>`），不再把 `</q>`、`</div>` 等其他标签误判为语音结束。
- 未闭合的语音段在流式过程中显示为普通文字，不提前生成语音卡；获得正确闭合标签后才显示卡片。
- 流式生成期间暂不反复清洗语音文字，在结束/停止生成后清洗一次，避免原文与清洗后的短文字交替显示。
- 移除语音卡整体 `transition: all`，减少卡片尺寸变化导致的视觉抖动。原有播放逻辑、个人档案主题和水印 CSS 均未修改。
- 适配机制没有在用户当前的 TT iOS 真机版本完成复测。遇到残余闪烁，请同时停用其他会修改 `.mes_text` 的美化或正则进行定位。
- TT 使用 Git URL 安装：先将 ZIP 解压后的文件上传到自己安装来源的仓库根目录，确保只有此适配版启用。请先备份旧版包，以便回滚。
